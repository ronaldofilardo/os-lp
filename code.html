// Governança Determinística

Metodologia Omni Sistemas

Engenharia de software determinística aplicada à geração de código assistida por IA. O agente propõe, mas o protocolo invariante audita e impõe conformidade estrita.

PILAR 01 spellcheck

Semântica ASD-STE100

Um conceito = um nome. Vocabulário estritamente controlado que elimina ambiguidades em classes, métodos e assinaturas de domínio corporativo.

Regra: Tolerância zero a sinônimos polimórficos não mapeados.
PILAR 02 layers

Arquitetura Limpa & SOLID

Separação estrita de camadas: regras de negócio puras isoladas de infraestrutura, bancos de dados, integrações de terceiros e frameworks web.

Regra: Dependências sempre apontam em direção ao domínio central.
PILAR 03 rule

Restrição Rígida

Limite estrito de 100 linhas por arquivo, proibição irrestrita de "any", encapsulamento try/catch obrigatório em toda operação assíncrona e segregação formal entre DB-Row e DTO.

Regra: Invariante de compilação sem casts ou supressões de erro.
PILAR 04 security

Skill Guardiã de IA

Agente/linter guardião determinístico que valida conformidade arquitetural e tipagem estrita antes de permitir a emissão ou commit de qualquer trecho de código.

Regra: Feedback em milissegundos com veto de merge automático.

UserDashboard.tsx 
// UI + Fetch acoplados, sem tipagem e sem try/catch
export default function UserDashboard() {
  const [data, setData] = useState<any>(null);

  useEffect(() => {
    // Alucinação comum: fetch direto no useEffect sem abort ou erro
    fetch('/api/users/billing')
      .then(res => res.json())
      .then(resData => {
        // Exposição direta de campos brutos da tabela
        setData(resData.raw_user_row);
      });
  }, []);

  return (
    <div>
      <h1>{data?.usr_nm_full || 'Carregando...'}</h1>
      <span>Saldo: {data?.acc_bal_cents}</span>
    </div>
  );
}
✕ Sem tipagem estrita: uso indiscriminado de any
✕ Lógica de API acoplada no componente de apresentação
✕ Sem tratamento de erro: falha silenciosa em caso de 500

// Clean View • DTO tipado rigidamente • Hook isolado
export function UserDashboardView() {
  const { account, isLoading, error } = useUserBilling();

  if (error) return <ErrorTelemetryNotice error={error} />;
  if (isLoading || !account) return <SkeletonMetricCard />;

  return (
    <MetricCardContainer>
      <TypographyHeadline>{account.customerName}</TypographyHeadline>
      <FormattedBalanceBadge value={account.formattedBalance} />
    </MetricCardContainer>
  );
}
